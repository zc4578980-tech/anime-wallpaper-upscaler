## Measurement Rules

- Record source URLs, dates, public repository Star counts, and relevant referrer data.
- Treat paid promotion, artificial engagement, duplicate counts, and unsupported estimates as
  context, never as proof of organic demand.
- The release-day baseline and day-30 checkpoint are the authoritative inputs for the 30 net-new
  Star goal. Candidate channels are useful only after an actual compliant placement exists.
