## English

**Pause a frame. Keep it on your desktop.**

Anime Wallpaper Upscaler turns anime screenshots into screen-ready Windows wallpapers using a
local 2x/3x/4x workflow. After setup, drag a screenshot onto the desktop shortcut; the tool detects
the screen and Vulkan GPU, preserves complete composition by default, and produces a detail
comparison.

- Local processing; screenshots are not uploaded
- Automatic screen and Vulkan GPU detection
- Verified detail comparison and real desktop result
- Official Real-ESRGAN NCNN/Vulkan inference; this project does not claim an original model

See the recorded K-ON! example, run evidence, and installation steps:
https://github.com/zc4578980-tech/anime-wallpaper-upscaler
