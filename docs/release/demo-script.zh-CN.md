# 60-90 秒中文演示脚本

目标时长：约 78 秒。录屏前准备一张自己创作或明确获准公开演示的竖图，以及包含 3-5 张
图片的测试文件夹。终端字号应能看清命令、`Target`、GPU 列表和最终路径。

## 旁白与画面

**0-8 秒：问题**

画面先展示把竖图直接“拉伸”成宽屏后的变形效果，再快速切到普通裁切导致人物或边缘内容
消失的效果。

旁白：“竖图做桌面壁纸，直接拉伸会变形，裁切铺满又容易丢掉原本的构图。”

**8-17 秒：官方原始超分**

展示官方 Real-ESRGAN 输出的 `<名称>_realesrgan_4x.png`，放大线条细节；随后缩回整图，说明
它仍然只是原比例的超分图片。

旁白：“官方 Real-ESRGAN 很适合做本地超分，但原始输出不会替你完成屏幕比例和壁纸构图。”

**17-27 秒：一次安装**

在仓库根目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

画面扫过上游来源和许可证提示、校验下载、本地 `.venv` 与快捷方式完成提示，不等待完整下载
过程。

旁白：“这个项目不自研模型。首次运行脚本，会在你确认上游条款后下载并校验官方 Windows
程序和模型。”

**27-38 秒：拖放文件夹**

把测试文件夹拖到 `Anime Wallpaper Upscaler` 桌面快捷方式，显示一次倍率提示。

旁白：“之后把一张、多张图片或整个文件夹拖进快捷方式就可以批量处理。”

**38-49 秒：自动检测与倍率**

选择 `3`，终端实录显示 `Target: 2560x1600`、可用 Vulkan GPU 列表和逐张进度。字幕短暂列出
`2x / 3x / 4x`。

旁白：“它会识别这台机器的 2560×1600 物理主屏和可用 GPU；倍率保留 2、3、4 三档，也都
能在命令行手动指定。”

**49-64 秒：完成壁纸**

打开成品 JPG，先完整展示前景四边，再展示模糊背景填充的宽屏边缘；与裁切版做短暂切换。

旁白：“默认 preserve 模式保留完整原图，只用同一张图的柔化背景补齐屏幕。需要铺满时才
主动选择 cover 裁切。”

**64-71 秒：批量结果与对比**

展示输出文件夹、自动对比图和 `anime-wallpaper-upscaler.log` 的成功/失败汇总。

旁白：“每张图都有壁纸和对比结果；批量日志会指出失败文件，不会让一张坏图中断整批。”

**71-78 秒：署名与行动**

画面显示仓库首页的上游署名和“与官方 Real-ESRGAN 的区别”表格，最后停在仓库地址：

https://github.com/zc4578980-tech/anime-wallpaper-upscaler

旁白：“超分推理由 Real-ESRGAN、realesrgan-ncnn-vulkan 和 ncnn 提供；本项目负责 Windows
壁纸工作流。安装和完整说明都在这个仓库。”

## 表达边界

- 不把上游推理或模型描述为本项目原创，也不说“可以修复所有细节”。
- 不承诺任何图片都能恢复真实细节；展示输入、倍率、GPU 和屏幕尺寸。
- 演示图只使用自己创作或明确获准公开再分发的素材。
- 不隐藏上游程序、模型、来源和许可证提示。
