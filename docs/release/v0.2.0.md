# Anime Wallpaper Upscaler v0.2.0

v0.2.0 packages a verified Windows wallpaper workflow around the official Real-ESRGAN
NCNN/Vulkan runtime. It keeps the complete source composition by default and adapts the result to
the physical primary display without uploading or generatively redrawing the image.

## Highlights

- One-click `install.cmd` setup with consent-gated Python bootstrap, pinned upstream download,
  archive size and SHA-256 verification, and automatic model installation.
- Drag-and-drop files or folders, or use repeated CLI inputs and recursive folder processing.
- Automatic physical-screen and Vulkan GPU detection with explicit overrides.
- Scale-aware 2x, 3x, and 4x model selection.
- Composition-preserving wallpaper output, raw upscale output, comparison images, batch logs,
  and per-image failure isolation.
- Codex Agent Skill mapping natural-language wallpaper requests to the same deterministic local
  wrapper options.

## Install

1. Download and extract the source archive, or clone the repository.
2. Double-click `install.cmd`.
3. Review the displayed upstream source and license notice, then approve the verified download.
4. Drag images or folders onto `scripts\run-wallpaper.cmd` or the created desktop shortcut.

Windows 10 or 11, a Vulkan-capable GPU, and enough disk space for the official runtime and models
are required. See the
[README](https://github.com/zc4578980-tech/anime-wallpaper-upscaler#readme) for CLI usage and
repair guidance.

## Boundaries

- Real-ESRGAN, `realesrgan-ncnn-vulkan`, ncnn, the executable, and the models are upstream work.
  This repository does not claim an original super-resolution algorithm or model.
- The executable and models are downloaded during first setup and are not bundled in this
  repository.
- Windows is the supported platform for v0.2.0, and inference requires a working Vulkan driver.
- Upscaling cannot reconstruct every detail absent from a very small or damaged source image.
