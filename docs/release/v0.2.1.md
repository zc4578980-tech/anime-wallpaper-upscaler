# Anime Wallpaper Upscaler v0.2.1

v0.2.1 is a focused Windows installer hotfix. The inference workflow, model selection, output
formats, and upstream Real-ESRGAN download remain unchanged.

## Fixed

- Prevent Windows PowerShell 5.1 from treating successful native stderr warnings as fatal setup
  errors when `ErrorActionPreference` is `Stop`.
- Keep `pip`, Python, and winget stderr visible while using their real process exit codes to
  decide success or failure.
- Preserve actionable failures for nonzero Python command exit codes.

The reported failure occurred when `pip` printed `Cache entry deserialization failed, entry
ignored` but returned exit code 0. v0.2.1 allows setup to continue in that case.

## Install

1. Download and extract the v0.2.1 source archive.
2. Double-click `install.cmd`.
3. Review the displayed upstream source and license notice, then approve the verified download.

The installer still downloads the official Real-ESRGAN NCNN/Vulkan release from its pinned
upstream URL and verifies both the expected archive size and SHA-256 before extraction.
